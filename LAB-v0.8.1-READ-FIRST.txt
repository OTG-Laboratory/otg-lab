OTG! LAB v0.8.1 — STOP RECREATING DELETED SPACES (QA HOTFIX)
For existing OTG! LAB v0.8 ONLY. Never copy these files into MAIN or RH Guide.

Cause confirmed in existing code: GT7 startup called gt7EnsureSpace(false), which
CREATES a Space when absent; FH6 startup called fh6EnsureSpace(false,true),
explicitly requesting recreation. Previously deleted empty Spaces reappeared at app launch.

Fix: GT7 reconciles only if a matching Space already exists; FH6 reconciles
only if present. The code no longer creates them in the background.
This does NOT delete any existing Space. GT7 can still be created via its
explicit user action; FH6 can still be added deliberately later.

   git commit -m "OTG! LAB v0.8.1 - Stop deleted GT7 and FH6 Spaces returning"
   git push
