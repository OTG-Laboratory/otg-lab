OTG! MAIN v8.0.65 — HISTORY / PICKUPS NORMALISATION / DRAG REDESIGN

MAIN ONLY — rh-guide remains unchanged.

1) PICKUPS & 4x4 NORMALISATION
- Canonical Class / Type is now: Pickups & 4x4
- Merges legacy Pickups & 4x4's / Pickups & 4x4s aliases in live FH5 Space data.
- Canonical source catalogue and FH5 programme tables updated so future reset/rebuilds do not recreate the split.
- Existing Class/Type and Hot Wheels runs using the old aliases are retargeted to the canonical value.

2) FESTIVAL + RACE OFF HISTORY
- Existing Race Off bottom-of-catalogue History block is removed.
- Festival and Race Off now get the same compact HISTORY tile in the hero/top area.
- Each opens a dedicated archive screen with completed date, entrant count, champion/winner and winning/total time.
- Tapping a Festival item reopens its completed standings/trophy route.
- Tapping a Race Off item reopens its champion/tournament route.
- Hall of Fame remains honours; Records remains performance history.

3) RACE OFF CATALOGUE PARITY
- Top order is OTG! Race Offs -> Favourite Manufacturer -> Lonely Hearts -> normal catalogue sections.
- Drag specialist events are removed from Race Off. Existing completed Drag Race Offs remain in History / Hall of Fame.

4) FH5 DRAG SHOOTOUT
- Festival Drag specialist events are now STANDARD / one round / one timed run per car.
- Fastest overall time wins.
- Track is fixed to suit the field:
  * Teotihuacan Drag Strip: Classic Muscle, Retro Muscle, Rods & Customs
  * Festival Drag Strip: Modern Muscle, Retro Super Cars, Super GT
  * Aerodromo Drag Strip: Hypercars, Modern Supercars, Extreme Track Toys
- Format/round editing is locked for Drag Shootouts.
- Existing prepared/active Drag Championships with zero results are safely migrated in place to the new one-run format. Existing Drag runs that already contain results are left untouched.

5) SAFETY BACKUP GATE HARDENING — REVISION 2
- The failed v8.0.64 -> v8.0.65 live update exposed a scaling weakness in the old updater: full Safety Backups for every Space were duplicated inside localStorage before install.
- Update Safety Backups now store their full verified payload in IndexedDB and keep only a tiny verified pointer in normal OTG! state. This avoids doubling a large Garage / frozen-event dataset inside localStorage.
- Safety restore understands the IndexedDB-backed protected backup.
- The v8.0.64 service worker is included as a same-version updater hotfix so an installed v8.0.64 can receive the repaired Safety gate before attempting v8.0.65 again.
- v8.0.65 data migrations are held until the update has actually been accepted, so the direct-new-index fallback cannot normalise live data before the Safety Backup gate.
